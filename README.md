# Seltronics

A modern, responsive electronics storefront designed for GitHub Pages.

## Pages
- Home
- Shop
- Categories
- About
- Contact
- Cart
- Wishlist
- 404

## Features
- Responsive mobile-first design
- Product catalog covering smartphones, laptops, tablets, TV, audio, gaming, wearables and accessories
- Category filtering and price sorting
- Browser-local cart and wishlist
- No backend required
- GitHub Pages ready

## Deploy
Upload the contents of this folder to a GitHub repository and enable **Settings → Pages → Deploy from a branch → main → /(root)**.
GitHub Pages publishes static HTML/CSS/JS directly from a repository.
